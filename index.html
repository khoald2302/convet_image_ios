Tôi đã cập nhật logic đặt tên file zip tự động dựa trên khung hình được chọn khi nén file: * **Tự động nhận diện thiết bị:** Hệ thống sẽ kiểm tra nhóm kích thước đang được chọn. Nếu thuộc nhóm iPhone (hoặc tỷ lệ màn hình điện thoại 9:16), file nén tải về sẽ tự động gắn hậu tố là `app-store-screenshots-iphone.zip`. * **Trường hợp còn lại (iPad / Tự nhập size lớn):** Ngược lại, file nén sẽ mang tên `app-store-screenshots-ipad.zip`. * **Đảm bảo tính chính xác:** Tên file zip được chốt dựa trên đúng kích cỡ của các bức ảnh đang có trong kết quả xuất ra, tránh bị nhầm lẫn ngay cả khi bạn bấm chọn ô kích thước khác sau khi đã resize.
